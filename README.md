# 도심 환경에서 재난 위치 판별을 통한 알림 서비스

행정안전부 긴급재난문자, 경찰청 안전Dream 실종 정보, 기상청 기상특보·지진·태풍 정보, 산림청 산사태 예측 정보를 수집하여 지도상에 표시한다. 시민 제보는 대상에 포함하지 않으며, 실종자 사진은 분석에 사용하지 않고 문자 원문만 이용한다.

## 자료

재난문자는 재난안전데이터공유플랫폼의 긴급재난문자 API로 수집한다. 해당 API는 생성일(`crtDt`) 단위로만 조회되므로, 운영 수집은 당일 및 전일 발령분으로 한정된다. 과거 기간은 동일 플랫폼의 공개 목록을 아카이브하여 2023년 9월부터의 발령 원문을 확보하였다. 아카이브에는 2025년 발령분 약 2만 3천 건이 포함되어 있으나, 실시간 적재만으로는 해당 연도가 공백으로 남으므로 아카이브 원문을 저장소에 병합하였다.

기상특보는 발효 중인 현황을 기준으로 하며, 해상 구역은 육지 행정구역으로 매핑하지 않는다. 기간 조회는 서울 시각 기준 시작일·종료일의 닫힌 구간으로 수행한다.

## 위치 판별

원문에서 지명을 추출할 때 생성형 모형에만 의존하면 발신 지역과 무관한 지명이 섞인다. 본 서비스는 다음 순서로 위치를 결정한다.

발신 기관명(`[진주시]` 등)을 행정구역으로 해석하여 탐색 범위를 고정한다. 이어서 법정동 사전으로 시·도, 시·군·구, 읍·면·동, 리를 대조한다. 도로명과 건물번호가 나타나면 지오코딩으로 좌표를 구하고, 실패 시 해당 시·군 중심점에 표시한다. 사전 매칭이 부족한 경우에 한하여 개체명 인식 모형과 언어 모형으로 지명만 보완한다.

리·면 명칭은 일반 명사·어미와 형태가 겹친다. `역류하면`, `요구하면`과 같이 동사 활용을 면으로 오인하는 경우, `구제역`을 역명으로 오인하는 경우, 교차로명(`…사거리`)에서 역만 잔존하는 경우를 규칙으로 제외한다. 실제 행정구역인 `상하면` 등은 사전에 있으면 유지한다. 발신 지자체와 시·군이 모순되는 후보는 버린다.

## 재난 유형

유형은 원문 키워드의 우선순위로 부여한다. 호우·폭염·태풍 등 기상 특보 표현이 있으면 해당 유형을 택하고, 댐 방류나 수위 안내만으로는 호우로 보지 않는다. 강풍 주의보·경보는 강풍으로 둔다. 서행 지시만으로 교통 사고로 분류하지 않으며, 폭발이라는 어휘만으로 화재로 보지 않는다. 구제역 발령은 축산 방역으로 둔다.

요약과 행동 안내는 유형별 규칙 문장으로 생성한다.

## 화면

주의보·경보와 같이 시·군 단위로 발효된 건은 해당 행정구역을 색칠하고, 실종·사고 등 지점이 특정된 건은 마커로 표시한다. 사용자는 시작일과 종료일을 지정하여 저장된 발령을 조회한다.
